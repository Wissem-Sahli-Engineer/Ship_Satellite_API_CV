The Project

Seeing the Seas from Above

Nautilus AI is a specialized computer vision pipeline designed to classify maritime vessels using satellite imagery. Built with TensorFlow Keras and served through a high-performance FastAPI backend.

🛰️

Orbital Intelligence

Trained on diverse satellite datasets to recognize vessel types from aerial perspectives with high accuracy, even in challenging weather conditions.

⚡

Real-Time Inference

Sub-second prediction times through optimized model architecture. The Keras model runs efficiently while maintaining classification precision.

🔧

Teachable Machine

Leveraging Google's Teachable Machine workflow for rapid prototyping and model iteration, enabling quick adaptation to new vessel classes.

🌐

REST API

Clean FastAPI endpoints with automatic documentation, CORS support, and structured JSON responses for easy integration into any stack.

🎯

High Precision

Fine-tuned classification confidence scores help distinguish between similar vessel types like cargo ships, tankers, and fishing vessels.

🚀

Production Ready

Containerized architecture ready for cloud deployment. The model serves predictions through a lightweight, scalable API interface.

<p>Satellite imagery provides unique insights into various markets, including agriculture, defense and intelligence, energy, and finance. New commercial imagery providers, such as <a href="https://www.planet.com/" target="_blank" aria-label="Planet (opens in a new tab)" rel="noreferrer nofollow">Planet</a>, are using constellations of small satellites to capture images of the entire Earth every day. </p>
<p>This flood of new imagery is outgrowing the ability for organizations to manually look at each image that gets captured, and there is a need for machine learning and computer vision algorithms to help automate the analysis process. </p>
<p>The aim of this dataset is to help address the difficult task of detecting the location of large ships in satellite images. Automating this process can be applied to many issues including monitoring port activity levels and supply chain analysis.</p>
<h1>Content</h1>
<p>The dataset consists of images extracted from Planet satellite imagery collected over the San Francisco Bay and San Pedro Bay areas of California. It includes 4000 80x80 RGB images labeled with either a "ship" or "no-ship" classification. Images were derived from PlanetScope full-frame visual scene products, which are orthorectified to a 3-meter pixel size. </p>
<p>Provided is a zipped directory <code>shipsnet.zip</code> that contains the entire dataset as .png images. Each individual image filename follows a specific format: {label} <em>_ {scene id} _</em> {longitude} _ {latitude}.png</p>
<ul>
<li><strong>label:</strong> Valued 1 or 0, representing the "ship" class and "no-ship" class, respectively. </li>
<li><strong>scene id:</strong> The unique identifier of the PlanetScope visual scene the image was extracted from. The scene id can be used with the <a href="https://www.planet.com/docs/reference/data-api/" target="_blank" aria-label="Planet API (opens in a new tab)" rel="noreferrer nofollow">Planet API</a> to discover and download the entire scene.</li>
<li><strong>longitude_latitude:</strong> The longitude and latitude coordinates of the image center point, with values separated by a single underscore. </li>
</ul>
<p>The dataset is also distributed as a JSON formatted text file <code>shipsnet.json</code>. The loaded object contains <strong>data</strong>, <strong>label</strong>, <strong>scene_ids</strong>, and <strong>location</strong> lists. </p>
<p>The pixel value data for each 80x80 RGB image is stored as a list of 19200 integers within the <strong>data</strong> list. The first 6400 entries contain the red channel values, the next 6400 the green, and the final 6400 the blue. The image is stored in row-major order so that the first 80 entries of the array are the red channel values of the first row of the image.</p>
<p>The list values at index <em>i</em> in <strong>labels</strong>, <strong>scene_ids</strong>, and <strong>locations</strong> each correspond to the <em>i</em>-th image in the <strong>data</strong> list.</p>
<h2>Class Labels</h2>
<p>The "ship" class includes 1000 images. Images in this class are centered on the body of a single ship. Ships of different sizes, orientations, and atmospheric collection conditions are included. Example images from this class are shown below. </p>
<p><img src="https://i.imgur.com/tLsSoTz.png" alt="ship"></p>
<p>The "no-ship" class includes 3000 images. A third of these are a random sampling of different land cover features - water, vegetation, bare earth, buildings, etc. - that do not include any portion of a ship. The next third are "partial ships" that contain only a portion of a ship, but not enough to meet the full definition of the "ship" class. The last third are images that have previously been mislabeled by machine learning models, typically caused by bright pixels or strong linear features. Example images from this class are shown below.</p>
<p><img src="https://i.imgur.com/cyG2Z54.png" alt="no-ship"></p>
<h1>Scenes</h1>
<p>Eight full-scene images are included in the <code>scenes</code> directory. Scenes can be used to visualize the performance of classification models trained on the dataset. Verify a model's accuracy by applying it across a scene and viewing where 'ship' classifications occur - the context provided by the scene helps determine positive hits from false alarms.
